# author-semantic-spaces

Репозиторий с кодом и материалами, сопровождающими научную статью о сопоставлении **авторских семантических пространств** (Word2Vec), обученных на корпусах художественных текстов русских писателей XIX века.

## Что внутри
- `preprocessing.ipynb` — сбор и предобработка авторских корпусов: очистка → сегментация на предложения → лемматизация и POS-разметка → токены `lemma_POS` → удаление стоп-слов.
- `w2v_train.ipynb` — обучение **отдельной** Word2Vec-модели для каждого автора + скачивание общеязыковой модели **Ruscorpora** (референс) и сохранение в локальный `.kv`.
- `w2v_compare.ipynb` — сравнение моделей на пересечении словарей несколькими методами: Orthogonal Procrustes (cosine displacement, LND), Gromov–Wasserstein, сравнение соседей (Jaccard, RBO).

## Быстрый запуск (локально)
1) Установите зависимости (как минимум): `gensim`, `numpy`, `pandas`, `matplotlib`, `seaborn`, `scipy`, `pot` (POT/ot), `bs4`, `pymystem3`, `nltk`, `joblib`, `tqdm`.
2) Запустите ноутбуки по порядку:
   - `preprocessing.ipynb`
   - `w2v_train.ipynb`
   - `w2v_compare.ipynb`

## Про модели в `models/`
В `models/` сохраняются результаты обучения (авторские модели) и референсная модель Ruscorpora. Файлы крупные; для хранения в репозитории используется Git LFS.

## Про исходные данные
Исходные текстовые данные (корпуса) **пока не выложены** в этот репозиторий и могут быть предоставлены позже. На текущий момент в репозитории опубликованы ноутбуки и **готовые обученные модели** в `models/`, достаточные для воспроизведения сравнения (`w2v_compare.ipynb`).
